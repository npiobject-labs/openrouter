Alias sin cargar

Un alias es un nombre de trabajo: una aplicación pide alias:mapeador y es el servicio quien decide el modelo, los parámetros por defecto y a qué recurrir si el primero no responde. Cambiar de modelo deja así de tocar el código de nadie. Cualquier clave puede verlos; solo la de administración puede tocarlos.
