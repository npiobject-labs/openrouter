## Lo que enseñó el VPS

La inspección evitó dos errores de diseño: no hacía falta un segundo Caddy ni
un puerto público, y el 8080 que el plan daba por hecho estaba ocupado. Y la
primera preparación dejó una lección de método: el `Caddyfile` importa
`sites.d/*.caddy` con comodín, el informe lo enseñaba expandido, y la línea
`import` explícita que añadió el script duplicó el sitio. `caddy validate` lo
rechazó, así que Caddy no se recargó y los otros dominios no se vieron
afectados, pero el run salió verde porque el `tee` se tragó el código de
salida. Ahora el script mira en la configuración adaptada si el dominio ya
está cargado antes de tocar nada, y los pasos por SSH llevan `pipefail`.
